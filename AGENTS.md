# Library Claim Agent

This is an independent repository. Node 22+, TypeScript, Express, React, native OpenAI REST APIs.
Run `npm run check` before committing. Never commit .env, real capture data, credentials, or personal information.
Unknown facts are null/empty and reviewed. No model-authored prices or metric dimensions. Monetary totals computed in code.
Keep recognition, measurement, pricing, review, and reporting separate. Every accepted price must have fetched evidence.
Do not claim ground-truth accuracy, reference voice testing, real capture, or a demo recording without real evidence.
