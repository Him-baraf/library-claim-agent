# Submission checklist

Code cannot substitute for physical measurements or a genuine demo. Complete this after the final live test.

- [ ] Private repository shared with the evaluator's GitHub account (not supplied in brief).
- [ ] Cold start tested in under 15 minutes; no credentials committed.
- [ ] Consent for space; no people/personal documents in capture.
- [ ] Ground truth before tuning: ≥60 books, ≥2 units, ≥8 non-book items, enclosed room.
- [ ] Every legible spine hand-read; 20 measured spines; 15 sourced/dated/condition-matched prices; tape-measured room.
- [ ] One unedited take ≤6 minutes, voice audible, continuous sweep, live inventory, final packet/readback.
- [ ] Same sweep JSON, readable report, saved referenced frames, sources, stages, transcript and metrics bundled.
- [ ] Same ten eligible books in second market, blanks and FX labelled honestly.
- [ ] Complete-run evaluation outputs, failed shelves retained; pass/fail/not-evaluated per bar.
- [ ] Architecture note; actual worst three errors; one measured attempted fix.
- [ ] Measured cost per sweep and latency per stage, with partial/unknown components disclosed.
- [ ] You send submission email with repo/video links and four documents. App sends no email.

Review privacy before sharing captures. `data/` is ignored to prevent accidental room-photo uploads. Upload the actual ZIP/demo privately or explicitly add reviewed artifacts. Never commit `.env`.
